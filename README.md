# 🎰 Telegram Casino Bot

**Telegram Casino Bot** — это телеграм-бот с набором мини-игр, таких, как **Слоты**, **Нвути**, **Мины**, а также системой баланса и таблицей лидеров. Проект написан на Python с использованием библиотеки [pyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI) и управляется через [Poetry](https://python-poetry.org/).

## 🚀 Возможности

- 🎰 **Слоты** — простая и быстрая игра. Делаете ставку и крутите барабаны. Выпавшие комбинации символов приносят выигрыш.
- 🎲 **Нвути** — игра с гибкой системой ставок:
  - Устанавливаете ставку
  - Выбираете шанс на победу (от 1 до 100)
  - Выбираете один из диапазонов: «больше» или «меньше»
  - Чем ниже шанс — тем выше потенциальный выигрыш
- 💣 **Мины** — игра на удачу. Выбирайте ячейки на поле 5x5:
  - 💎 Множители увеличивают выигрыш
  - 💥 Попадание на мину завершает игру
- 💵 **Система баланса** — у каждого пользователя свой виртуальный баланс.
- 🏆 **Таблица лидеров** — отображает топ игроков по количеству монет.

## 🛠️ Установка

> Убедитесь, что у вас установлен Python 3.10+ и Poetry.

1. Клонируйте репозиторий:

```bash
git clone https://github.com/aaafeig/fortuna_bot
cd fortuna_bot
```

2. Установите зависимости с помощью Poetry:

```bash
poetry install
```

3. Создайте бота со своим токеном из примера example.env:

```python
# conf.py
import os
import telebot
from dotenv import load_dotenv

load_dotenv()

TOKEN = os.getenv('YOUR_TELEGRAM_BOT_TOKEN')
bot = telebot.TeleBot(TOKEN)
```

4. Запуск бота:

```bash
poetry run python main.py
```
